# Roadmap

## Phase 1 — Deterministic Ingestion

- ingest markdown source files into a structured wiki
- validate metadata and required sections
- report on link integrity and provenance

## Phase 2 — LLM Synthesis

- integrate LLMs for generating richer content
- produce narrative summaries from wiki structure
- add LLM-assisted metadata extraction

## Phase 3 — Graph Generation

- generate knowledge graphs from wiki pages and links
- visualize relationships and dependencies
- support entity and architecture graph views

## Phase 4 — Multi-Agent Maintenance

- automate wiki updates with agents
- enable review workflows for content consistency
- support self-healing links and provenance checks

## Phase 5 — Enterprise Governance

- add policies for access control and audit trails
- support enterprise-grade reporting and compliance
- integrate approvals, versioning, and change workflows
