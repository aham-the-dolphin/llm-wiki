# ADR 0002: Provenance Requirements

## Context

Provenance is critical for trust, auditability, and legal compliance in knowledge systems.

## Decision

Every wiki page must include structured metadata and explicit provenance sections. The system must generate a provenance report that grades completeness.

## Consequences

- provenance becomes an enforceable quality gate
- missing metadata and sections are visible to maintainers
- content can be traced back to source references and update history
